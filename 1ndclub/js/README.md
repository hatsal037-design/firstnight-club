# 첫밤 페이지 코드 (2026-08-23 나눔)

`index.html` 한 파일에 1,667줄이 인라인으로 들어 있던 것을 역할별로 나눴다.
코드는 한 글자도 바꾸지 않고 자른 것뿐이다.

## 실행 순서 — 바꾸지 말 것

순수 스크립트라 전역이 그대로 이어진다. `index.html` 의 `<script>` 순서가
곧 실행 순서이고, 앞 파일이 만든 값을 뒷 파일이 쓴다.

| 순서 | 파일 | 하는 일 |
|---|---|---|
| 1 | `state.js` | 상태·설정. 다른 파일이 모두 읽는 값 (`ROUNDS` · `acc` · `favs` · `PENDING_APPLY` …) |
| 2 | `auth.js` | 세션 부팅(`bootSession`) · 카카오 로그인 · 알림함 · 뷰 전환 |
| 3 | `catalog.js` | 게임 도감 — 목록·검색·분류·인원 필터·즐겨찾기 |
| 4 | `sched.js` | 정모일정 — 회차 티켓·상세·지난 회차 더보기·할 게임 고르기 |
| 5 | `people.js` | 참여자 표기 · 프로필 카드 · 서기 각성 · 좋알람 |
| 6 | `records.js` | 지난정모 편집 · 마이페이지 · 회원관리 |
| 7 | `detail.js` | 게임 상세 창 |
| 8 | `start.js` | 첫 그림 · `bootSession()` 호출 · `?apply=` 티켓 공유 링크 |

`state.js` 는 반드시 맨 먼저, `start.js` 는 반드시 맨 나중.
가운데 여섯은 함수 선언만 있어서 서로 순서를 바꿔도 되지만, 굳이 바꿀 이유가 없다.

## 새 기능을 넣을 때

- 어느 역할인지 고르고 그 파일에 넣는다. 애매하면 화면 이름을 따라간다.
- 새 파일을 만들면 `index.html` 의 `<script>` 줄과 이 표에 함께 추가한다.
- 버전(`?v=`)은 고친 파일만 올리면 된다.

## 이 폴더 밖

- `../api.js` — 서버(Supabase)와 이야기하는 층. 화면 코드는 여기만 부른다
- `../../tunel.js` — 노선 공용(티켓·신청·알림). 티켓 규칙은 `개발/티켓_규칙.md`
- `../games.js` · `../games_db.js` — 게임 자료
- `../schedule.js` — 서버를 못 읽을 때 쓰는 폴백 회차
