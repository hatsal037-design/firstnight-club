# 게임 사진 넣는 법

1. 이 폴더에 사진을 넣는다. 파일명은 자유지만 게임 이름으로 하면 찾기 쉽다.
   예) `달무티.jpg`, `시크릿히틀러.jpg`

2. `games.js`에서 그 게임 줄에 `img:'img/달무티.jpg'` 를 추가한다.

   { n:'달무티', min:4, max:8, t:15, ..., img:'img/달무티.jpg' },

3. 끝. 사진이 없는 게임은 이름 앞글자로 만든 커버가 자동으로 뜬다.

## 사진 고를 때

- 정사각형에 가깝게 잘라두면 제일 깔끔하다 (앱에서 정사각형으로 보여줌)
- 한 변 200px 정도면 충분하다. 크면 앱이 느려진다
- 직접 찍은 박스 사진이 제일 좋다. 판매 사이트 이미지를 그대로 가져다 쓰면
  저작권 문제가 생길 수 있다

# 룰 사진 넣는 법

룰 설명에 쓸 사진은 `img/rules/` 안에 넣는다.
그다음 `games.js` 의 그 게임 `rules` 배열에 한 줄 추가한다.

    { img:'img/rules/mafia-setup.jpg', cap:'8명 기준 역할 카드 구성' },

`cap` 은 사진 밑에 붙는 설명이고, 없어도 된다.
